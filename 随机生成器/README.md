# 下一件 · 奇怪事物档案馆

一个按钮，遇见任何东西。这是一个完全本地运行的小网站：点一下"随机一下"，你会得到一件真实或虚构、严肃或离谱的内容，然后可以一直点下去。

## 怎么用

**最简单的方式**：直接双击 `index.html`，就能在浏览器里打开玩（所有数据和代码都打包在文件里，不联网也能用）。

**想发给别人 / 部署到网上**：把整个文件夹传到任意"静态网站托管"（GitHub Pages、Vercel、Netlify、Cloudflare Pages 都行），不需要服务器，不需要数据库，不需要登录。

## 里面有什么

- 540+ 条内容，覆盖 25 个类别：动物、宇宙、人体、历史、地理、科技、语言、数学、哲学、脑洞、未解之谜……（故事类保持少量精选）
- 每条内容标得清清楚楚：**科学 / 真实 / 历史 / 虚构 / 传说 / 娱乐**，不会把编的当真的。
- 智能随机：最近看过的不会马上重复，同类内容不会连着刷屏，偶尔会触发稀有内容和隐藏系列。
- 你的所有数据（收藏、历史、成就、统计）都存在你自己的浏览器里，不联网、不上传。

## 常用操作

- 空格键 / 右方向键：下一件
- ☰ 我的档案：历史、收藏、统计、成就、今日发现
- ✉ 给未来的自己留一句话：7 天或 30 天后，它会以"来自过去的你"的形式随机出现
- ♥ 收藏 · ✕ 不感兴趣（点一下自动换一个）· ↳ 深入了解 · 分享

## 想加新内容？

内容都在 `data/` 文件夹的 JSON 文件里（比如 `animals.json` 是动物类）。加完内容后，在电脑上运行：

```text
node tools/build-index.js
node tools/build-embed.js
node tools/build-bundle.js
```

然后刷新页面，新内容就会出现。详细说明见 `tools/README.md`。

## 部署到网上（免费）

这个网站是纯静态的，不需要服务器、不需要数据库、不需要登录。下面以 GitHub Pages 和 Netlify 为例：

### 方式一：Netlify（最简单，推荐）

1. 打开 https://app.netlify.com/drop
2. 把整个文件夹拖进网页
3. 等几秒，它会给你一个网址（比如 xxx.netlify.app），完成

以后更新内容：重新拖一遍文件夹即可（或者用 GitHub 方式自动更新）。

### 方式二：GitHub Pages（适合长期维护）

1. 注册 GitHub，新建一个仓库（Repository）
2. 把整个文件夹上传到仓库
3. 在仓库 Settings → Pages 里，把发布源选为 `main` 分支的根目录
4. 等 1-2 分钟，你的网址就是 `https://你的用户名.github.io/仓库名/`

以后更新：把新文件推到仓库，网站自动更新。

### 方式三：Vercel / Cloudflare Pages

- Vercel：https://vercel.com → New Project → 导入文件夹即可
- Cloudflare Pages：https://pages.cloudflare.com → 上传文件夹即可

无论哪种方式，最终都是把整个文件夹原样传上去，不需要改任何配置。

## 常见问题

- **内容会重复吗？** 最近 150+ 条不重复；内容库还会继续扩充，扩充后"不重复窗口"会更大。
- **需要联网吗？** 不需要。所有内容都在本地文件里。
